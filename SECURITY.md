# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them privately via [GitHub's private vulnerability reporting](https://github.com/deplox/laravel-shield/security/advisories/new), or email [jonagoldman@gmail.com](mailto:jonagoldman@gmail.com) directly.

Include as much detail as possible: steps to reproduce, affected versions, and any suggested fix. You'll receive a response within 72 hours.
